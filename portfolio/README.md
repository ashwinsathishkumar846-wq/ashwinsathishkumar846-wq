# Madhumitha T — Portfolio (single HTML file)

`Madhumitha_T_Portfolio.html` is a complete, self-contained website: HTML, CSS, JavaScript,
fonts (Playfair Display, DM Sans, DM Mono — SIL Open Font Licence) and the resume PDF are all
embedded. It needs no internet connection, build step or server.

## Preview
Double-click the file to open it in any modern browser (Chrome, Edge, Firefox, Safari).

## Deploy (free static hosting)
- **Netlify Drop:** go to app.netlify.com/drop and drag the file in (rename it to `index.html` first).
- **GitHub Pages:** add it to a repository as `index.html`, then enable Pages in the repository settings.
- **Vercel / Cloudflare Pages:** create a project from a folder containing `index.html`.

## Editing
- Contact details, text and project content are plain HTML in the file.
- The embedded resume is the base64 string in `RESUME_B64` inside the script.
- To add a LinkedIn link later, add an `<a>` in the contact card; none is included because no profile URL was provided.
- The page presents skills, projects, experience and contact details; it does not ask for a specific internship.
