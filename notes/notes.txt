# 1️⃣ DOM EVENT HANDLING USING JAVASCRIPT

## What you need to know

For a 10-mark answer, remember these concepts:

- DOM = Document Object Model
- HTML elements become DOM objects
- JavaScript can access and modify them
- Events = user/browser actions
- Event handling = responding to events
- `getElementById()`
- `addEventListener()`
- `.value`
- `.innerHTML`
- `.style`

The **master pattern** is:

```text
HTML element
     ↓
getElementById()
     ↓
addEventListener()
     ↓
User performs event
     ↓
JavaScript function executes
     ↓
DOM is modified
```

## ⭐ MASTER DOM PROGRAM

This one demonstrates:

- button click
- input
- DOM access
- changing text
- changing CSS
- calculation
- multiple event handlers

```html
<!DOCTYPE html>
<html>
<head>
    <title>DOM Event Handling</title>

    <style>
        body {
            font-family: Arial;
            padding: 30px;
        }

        .box {
            width: 400px;
            padding: 20px;
            border: 2px solid black;
        }

        button {
            padding: 10px;
            margin: 5px;
        }
    </style>
</head>

<body>

<div class="box">

    <h2 id="title">Product Calculator</h2>

    <label>Product Name:</label>
    <input type="text" id="name">

    <br><br>

    <label>Price:</label>
    <input type="number" id="price">

    <br><br>

    <label>Quantity:</label>
    <input type="number" id="quantity">

    <br><br>

    <button id="calculate">Calculate</button>
    <button id="change">Change Style</button>

    <h3 id="result"></h3>

</div>

<script>

document.getElementById("calculate").addEventListener("click", function() {

    let name = document.getElementById("name").value;

    let price = document.getElementById("price").value;

    let quantity = document.getElementById("quantity").value;

    let total = price * quantity;

    document.getElementById("result").innerHTML =
        "Product: " + name + "<br>Total Price: ₹" + total;

});


document.getElementById("change").addEventListener("click", function() {

    document.getElementById("title").style.color = "blue";

    document.getElementById("result").style.fontSize = "20px";

});

</script>

</body>
</html>
```

## What to write for theory

### DOM

> The Document Object Model (DOM) represents an HTML document as a tree of objects. JavaScript can access and manipulate these objects to dynamically change HTML content, attributes and CSS styles.

### Event

> An event is an action that occurs in a web page, such as a mouse click, keyboard input or form submission.

### Event handling

> Event handling is the process of detecting an event and executing a function in response to that event.

### `addEventListener()`

```javascript
element.addEventListener("click", function() {
    // action
});
```

It attaches an event handler to an HTML element.

# ⭐ MASTER NODE + MONGODB CRUD PROGRAM

```javascript
const { MongoClient } = require("mongodb");

const url = "mongodb://127.0.0.1:27017";

const client = new MongoClient(url);

async function main() {

    try {

        // CONNECT
        await client.connect();

        console.log("MongoDB Connected");

        const db = client.db("bookstore");

        const books = db.collection("books");


        // =========================
        // CREATE
        // =========================

        await books.insertOne({
            title: "JavaScript Basics",
            author: "John",
            genre: "Programming",
            stock: 10
        });

        console.log("Book inserted");


        // =========================
        // READ
        // =========================

        const allBooks = await books.find().toArray();

        console.log("Books:");

        console.log(allBooks);


        // =========================
        // UPDATE
        // =========================

        await books.updateOne(
            { title: "JavaScript Basics" },
            { $set: { stock: 15 } }
        );

        console.log("Book updated");


        // =========================
        // DELETE
        // =========================

        await books.deleteOne({
            title: "JavaScript Basics"
        });

        console.log("Book deleted");


    } catch (error) {

        console.log(error);

    } finally {

        await client.close();

        console.log("MongoDB connection closed");
    }
}

main();
```

# ⭐ MASTER ANGULARJS FORM VALIDATION PROGRAM

```html
<!DOCTYPE html>
<html>

<head>

    <title>AngularJS Form Validation</title>

    <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js">
    </script>

    <style>

        body {
            font-family: Arial;
            padding: 30px;
        }

        .box {
            width: 400px;
            padding: 20px;
            border: 2px solid black;
        }

        input {
            width: 90%;
            padding: 8px;
            margin: 5px;
        }

        .error {
            color: red;
        }

        button {
            padding: 10px 20px;
        }

    </style>

</head>

<body ng-app="myApp">

<div ng-controller="formController">

    <div class="box">

        <h2>Registration Form</h2>

        <form name="myForm" ng-submit="submitForm()" novalidate>


            <!-- NAME -->

            <label>Name:</label>

            <input
                type="text"
                name="name"
                ng-model="user.name"
                required
                ng-minlength="3">

            <p class="error"
               ng-show="myForm.name.$touched && myForm.name.$invalid">

                Name must contain at least 3 characters.

            </p>


            <!-- EMAIL -->

            <label>Email:</label>

            <input
                type="email"
                name="email"
                ng-model="user.email"
                required>

            <p class="error"
               ng-show="myForm.email.$touched && myForm.email.$invalid">

                Enter a valid email address.

            </p>


            <!-- AGE -->

            <label>Age:</label>

            <input
                type="number"
                name="age"
                ng-model="user.age"
                required
                min="18"
                max="60">

            <p class="error"
               ng-show="myForm.age.$touched && myForm.age.$invalid">

                Age must be between 18 and 60.

            </p>


            <!-- PASSWORD -->

            <label>Password:</label>

            <input
                type="password"
                name="password"
                ng-model="user.password"
                required
                ng-minlength="6">

            <p class="error"
               ng-show="myForm.password.$touched &&
                        myForm.password.$invalid">

                Password must contain at least 6 characters.

            </p>


            <br>

            <button type="submit"
                    ng-disabled="myForm.$invalid">

                Submit

            </button>

        </form>


        <h3>{{message}}</h3>

    </div>

</div>


<script>

var app = angular.module("myApp", []);


app.controller("formController", function($scope) {

    $scope.user = {};

    $scope.message = "";


    $scope.submitForm = function() {

        if ($scope.myForm.$valid) {

            $scope.message =
                "Form submitted successfully!";

        }

    };

});

</script>

</body>

</html>
```

# ⭐ MASTER REACT APPLICATION

For exam purposes, this is the kind of application I recommend learning.

It contains:

```jsx
import React, { useState } from "react";
import "./App.css";


function Recipe({ recipe, onDelete }) {

    return (

        <div className="card">

            <h3>{recipe.title}</h3>

            <p>{recipe.description}</p>

            <p>
                Cooking Time: {recipe.time} minutes
            </p>

            <button
                onClick={() => onDelete(recipe.id)}>
                Delete
            </button>

        </div>

    );
}


function App() {

    const [recipes, setRecipes] = useState([
        {
            id: 1,
            title: "Pizza",
            description: "Cheese pizza",
            time: 30
        },

        {
            id: 2,
            title: "Pasta",
            description: "Creamy pasta",
            time: 20
        }
    ]);


    const [title, setTitle] = useState("");

    const [description, setDescription] = useState("");

    const [time, setTime] = useState("");

    const [search, setSearch] = useState("");


    function addRecipe(event) {

        event.preventDefault();

        if (title === "" || description === "" || time === "") {
            return;
        }


        const newRecipe = {

            id: Date.now(),

            title: title,

            description: description,

            time: time

        };


        setRecipes([...recipes, newRecipe]);


        setTitle("");

        setDescription("");

        setTime("");

    }


    function deleteRecipe(id) {

        setRecipes(
            recipes.filter(recipe => recipe.id !== id)
        );

    }


    const filteredRecipes = recipes.filter(recipe =>
        recipe.title
            .toLowerCase()
            .includes(search.toLowerCase())
    );


    return (

        <div className="container">

            <h1>Recipe Management</h1>


            {/* SEARCH */}

            <input
                type="text"
                placeholder="Search recipe"
                value={search}
                onChange={(e) => setSearch(e.target.value)}
            />


            {/* ADD FORM */}

            <form onSubmit={addRecipe}>

                <input
                    type="text"
                    placeholder="Recipe title"
                    value={title}
                    onChange={(e) => setTitle(e.target.value)}
                />


                <input
                    type="text"
                    placeholder="Description"
                    value={description}
                    onChange={(e) =>
                        setDescription(e.target.value)
                    }
                />


                <input
                    type="number"
                    placeholder="Cooking time"
                    value={time}
                    onChange={(e) =>
                        setTime(e.target.value)
                    }
                />


                <button type="submit">
                    Add Recipe
                </button>

            </form>


            {/* RECIPE LIST */}

            <div>

                {filteredRecipes.map(recipe => (

                    <Recipe
                        key={recipe.id}
                        recipe={recipe}
                        onDelete={deleteRecipe}
                    />

                ))}

            </div>

        </div>

    );
}


export default App;
```

# 1. Installation of NPM — Steps ⭐⭐⭐⭐⭐

## First: What is NPM?

**NPM = Node Package Manager.**

It is the package manager used with Node.js to install, manage and share JavaScript packages/modules.

### Installation steps

First install **Node.js** from the official Node.js website. NPM is normally installed along with Node.js.

Verify installation:

```bash
node -v
```

Check NPM:

```bash
npm -v
```

Create a project:

```bash
mkdir myapp
cd myapp
```

Initialize the project:

```bash
npm init -y
```

Install a package:

```bash
npm install mongodb
```

### ⭐ 2-mark answer

> **NPM (Node Package Manager) is used to install and manage packages required by Node.js applications. After installing Node.js, NPM can be verified using `npm -v`. A project can be initialized using `npm init -y`, and packages can be installed using `npm install package-name`.**

### Remember:

```text
node -v
npm -v
npm init -y
npm install package-name
```

# 2. Role of REST API ⭐⭐⭐⭐⭐

## What is REST?

**REST = Representational State Transfer.**

A REST API allows different applications to communicate over HTTP.

For example:

```text
React Application
       ↓
    REST API
       ↓
Node.js Server
       ↓
    MongoDB
```

Common HTTP methods:

| Method | Purpose |
|---|---|
| GET | Retrieve data |
| POST | Create data |
| PUT | Update data |
| DELETE | Delete data |

### Example

```text
GET /students
```

gets students.

```text
POST /students
```

creates a student.

### ⭐ 2-mark answer

> **A REST API enables communication between client and server using HTTP. It allows resources to be created, retrieved, updated and deleted using methods such as POST, GET, PUT and DELETE. REST APIs are commonly used to connect web applications with server-side applications and databases.**

### Remember:

```text
GET    → Read
POST   → Create
PUT    → Update
DELETE → Delete
```

🔥 This is directly connected to your **Node.js + MongoDB CRUD** 10-mark question.

# 3. Traditional Website vs Single Page Application ⭐⭐⭐⭐⭐

This is very easy if you remember the fundamental difference.

## Traditional Website

When moving between pages, the browser generally requests and loads another HTML page.

```text
Page 1
 ↓
Reload
 ↓
Page 2
 ↓
Reload
 ↓
Page 3
```

## SPA

**SPA = Single Page Application**

The application loads a main page and JavaScript dynamically updates the content without requiring a complete page reload for every action.

```text
One main page
      ↓
JavaScript
      ↓
Content changes dynamically
```

### Comparison

| Traditional Website | SPA |
|---|---|
| Multiple page loads | Mainly one page |
| Full-page reloads | Dynamic updates |
| Navigation can involve server requests for new pages | JavaScript updates the view |
| Simpler traditional architecture | Rich interactive UI |

### ⭐ 2-mark answer

> **A traditional website loads separate HTML pages and may perform a full-page reload during navigation. A Single Page Application (SPA) loads one main page and dynamically updates its content using JavaScript without completely reloading the page.**

### Examples of technologies associated with SPA

```text
AngularJS
React
Vue
```

# 4. AngularJS Directives ⭐⭐⭐⭐⭐

This is **very important** because your previous paper directly tested directives.

## What is a directive?

An AngularJS directive is a special instruction added to HTML that extends HTML's functionality.

They usually begin with:

```text
ng-
```

### Important directives

```html
ng-app
ng-controller
ng-model
ng-init
ng-repeat
ng-click
ng-show
ng-hide
ng-bind
```

### What they do

| Directive | Purpose |
|---|---|
| `ng-app` | Defines AngularJS application |
| `ng-controller` | Specifies controller |
| `ng-model` | Provides data binding |
| `ng-init` | Initializes data |
| `ng-repeat` | Repeats HTML elements |
| `ng-click` | Handles click |
| `ng-show` | Shows element |
| `ng-hide` | Hides element |
| `ng-bind` | Binds/displays data |

### Example

```html
<div ng-app="myApp" ng-controller="myCtrl">

    <input ng-model="name">

    <p>{{name}}</p>

</div>
```

### ⭐ 2-mark answer

> **AngularJS directives are special instructions added to HTML that extend its functionality and provide AngularJS features. Examples include `ng-app`, `ng-controller`, `ng-model`, `ng-repeat` and `ng-click`.**

### 🔥 If they ask:

> Which directive binds HTML controls to data?

Answer:

```text
ng-model
```

> Which directive initializes AngularJS?

```text
ng-app
```

# 5. Hello World Using ReactJS ⭐⭐⭐⭐

This is a very likely short question because your previous paper literally had it.

## Basic React program

```jsx
import React from "react";
import ReactDOM from "react-dom/client";

function App() {
    return <h1>Hello World</h1>;
}

const root = ReactDOM.createRoot(
    document.getElementById("root")
);

root.render(<App />);
```

HTML:

```html
<div id="root"></div>
```

### Output

```text
Hello World
```

---

## Understand the code

This:

```jsx
function App() {
    return <h1>Hello World</h1>;
}
```

is a React component.

This:

```jsx
<h1>Hello World</h1>
```

is **JSX**.

This:

```javascript
ReactDOM.createRoot(...)
```

creates the React root.

This:

```javascript
root.render(<App />);
```

renders the component into the DOM.

### ⭐ 2-mark answer

> **ReactJS can display Hello World by creating a functional component that returns JSX and rendering it into the root DOM element using `ReactDOM.createRoot()` and `root.render()`.**

### Remember:

```text
Component → JSX → createRoot() → render()
```

# 6. Two-Way Data Binding in AngularJS ⭐⭐⭐⭐⭐

This is one of your **most important 2-mark questions**.

Two-way binding means:

```text
       Model
       ↕
    ng-model
       ↕
       View
```

Data flows in **both directions**.

### Example

```html
<input ng-model="name">

<p>Hello {{name}}</p>
```

If the model changes:

```javascript
$scope.name = "Ajay";
```

the view updates.

If the user types something into the input:

```text
Input → Model
```

the model also updates.

### ⭐ 2-mark answer

> **Two-way data binding in AngularJS synchronizes the model and the view. Changes in the model are automatically reflected in the view, and changes made by the user in the view update the model. The `ng-model` directive is used for two-way binding.**

### 🔥 Most important keyword:

```text
ng-model
```

### Easy memory:

```text
Model ↔ View
```

# 7. Filters in AngularJS ⭐⭐⭐⭐⭐

A filter is used to **format or transform data before displaying it**.

For example:

```html
{{name | uppercase}}
```

If:

```text
name = "ajay"
```

output:

```text
AJAY
```

---

## Important built-in filters

| Filter | Purpose |
|---|---|
| `uppercase` | Converts to uppercase |
| `lowercase` | Converts to lowercase |
| `currency` | Formats currency |
| `number` | Formats numbers |
| `date` | Formats dates |
| `orderBy` | Sorts data |
| `filter` | Filters data |
| `limitTo` | Limits displayed data |

### Examples

```html
{{name | uppercase}}
```

```html
{{price | currency}}
```

```html
{{name | lowercase}}
```

```html
{{students | orderBy:'name'}}
```

### ⭐ 2-mark answer

> **Filters in AngularJS are used to format or transform data before displaying it in the view. Common built-in filters include `uppercase`, `lowercase`, `currency`, `number`, `date`, `orderBy`, `filter` and `limitTo`.**

### 🔥 Remember:

```text
uppercase
lowercase
currency
number
date
orderBy
filter
limitTo
```

# 8. Modules and Controllers in AngularJS ⭐⭐⭐⭐⭐

This looks complicated but it's actually simple.

## Module

A module is a **container for an AngularJS application and its components**.

Example:

```javascript
var app = angular.module("myApp", []);
```

---

## Controller

A controller contains the **application logic and data**.

```javascript
app.controller("myCtrl", function($scope) {

    $scope.name = "Ajay";

});
```

HTML:

```html
<div ng-app="myApp" ng-controller="myCtrl">

    {{name}}

</div>
```

Output:

```text
Ajay
```

---

## Relationship

Remember:

```text
Module
   ↓
Controller
   ↓
$scope
   ↓
View
```

### ⭐ 2-mark answer

> **A module is a container that organizes an AngularJS application and its components. A controller contains the application's logic and data and communicates with the view using `$scope`.**

### Important syntax

```javascript
var app = angular.module("myApp", []);

app.controller("myCtrl", function($scope) {
    $scope.name = "Ajay";
});
```

# 9. File Operations in Node.js ⭐⭐⭐⭐⭐

Node.js provides the **File System (`fs`) module** for working with files.

First import it:

```javascript
const fs = require("fs");
```

---

## Create/Write a file

```javascript
fs.writeFile("data.txt", "Hello World", function(err) {

    if (err) throw err;

    console.log("File created");

});
```

---

## Read a file

```javascript
fs.readFile("data.txt", "utf8", function(err, data) {

    if (err) throw err;

    console.log(data);

});
```

---

## Append data

```javascript
fs.appendFile("data.txt", "Welcome", function(err) {

    if (err) throw err;

    console.log("Data added");

});
```

---

## Delete a file

```javascript
fs.unlink("data.txt", function(err) {

    if (err) throw err;

    console.log("File deleted");

});
```

---

## ⭐ The four operations you MUST remember

```text
writeFile()
    ↓
Create / Write

readFile()
    ↓
Read

appendFile()
    ↓
Add data

unlink()
    ↓
Delete
```

### ⭐ 2-mark answer

> **Node.js provides the built-in `fs` (File System) module for performing file operations. Common methods are `fs.writeFile()` for writing, `fs.readFile()` for reading, `fs.appendFile()` for adding data and `fs.unlink()` for deleting a file.**

### Important syntax:

```javascript
const fs = require("fs");
```
