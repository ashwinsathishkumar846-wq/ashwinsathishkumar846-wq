SIMULATION RESULTS FOR UNDERSTANDING  (not for Coursera submission)
===================================================================
These are REAL simulation results of the five VHDL designs (counter, RAM, FSM, ALU, FIFO), produced with the
free GHDL simulator using small "demo" testbenches that apply easy-to-follow inputs.

* Simulation_Results_for_understanding.pdf  - 5 pages: waveform + cycle-by-cycle table + explanation per design.
* raw_traces/        - the same data as CSV (open in Excel) and the page images.
* waveforms_gtkwave/ - .vcd waveform files; open them in the free GTKWave viewer to zoom around the signals.
* demo_testbenches/  - the testbenches that created the traces (read them to see how the designs are driven).

IMPORTANT: this is NOT the course's myvectorh.out. That file is written by the course's encrypted testbench in
ModelSim and cannot be reproduced here, so none of these files can be uploaded to Coursera.
